Keyed "<chainId>:<verifyingContract>:<schema hash>", each entry is Ledger's
signed name for a typed message and a signed label and format per field.
qeth checks every signature against Ledger's key before the Ledger gets it
(qeth/ledger_metadata.py), and looks messages up locally, so signing tells no
server what is signed (docs/ledger-clear-signing.md).
